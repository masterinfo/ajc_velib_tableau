# ajc_velib_tableau
projet velib mysql tableau
TP — Visualiser la disponibilité des stations Vélib’ à Paris
Travaux pratiques Data Visualisation  ·  Open Data Paris → MySQL → ODBC → Tableau Desktop
1. Contexte et objectif
Vous devez réaliser un projet de visualisation de données permettant d’explorer la disponibilité des stations Vélib’ à Paris.
À partir des données d’Open Data Paris, vous construirez une chaîne complète : collecte des données, préparation, stockage dans MySQL, connexion à Tableau Desktop et création de tableaux de bord. Le projet suit l’architecture présentée dans le schéma ci-dessous.
Modalités : projet déposé sur GitHub, soutenance orale de 10 à 15 minutes, au minimum 4 tableaux de bord dont les thèmes et les visualisations sont laissés au choix de l’apprenant.
2. Compétences visées
À l’issue du TP, vous devrez être capable de :
•	Collecter et comprendre un jeu de données ouvertes.
•	Nettoyer, transformer et importer des données dans une base relationnelle.
•	Concevoir des requêtes SQL adaptées à une analyse.
•	Connecter Tableau Desktop à MySQL.
•	Construire des tableaux de bord pertinents et interactifs.
•	Documenter un projet pour permettre sa reprise.
•	Présenter vos résultats et justifier vos choix.
